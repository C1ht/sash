# v1 release gates

Items that must hold before a v1 release. Each is checked and reported when v1 is
prepared.

- [ ] Debug recording (feature `debug-record`, docs/DEBUG.md) removed, or proven
  compiled out of the release binary (tools/check-release.sh).
- [ ] Candidate (owner's decision pending, after M16): a screen reader is usable
  for the shell and Settings (the AccessKit adapter is decided before the
  Settings app).
