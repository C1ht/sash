# Design reference images

The owner's concept images from the design canvas (2026-11-07), the
source that docs/design.md was frozen from. They show roughly what Sash
is meant to look like; where an image and docs/design.md or CLAUDE.md
disagree, the text wins. Window contents (terminals, browser pages) are
mock-ups, not real data.

| File | Shows |
|---|---|
| 01-tiled-bottom-dock.png | Tiling at 5120x1440, the dock at the bottom (launcher, apps, separator, minimized window, tray, clock) |
| 02-tiled-left-dock-glass-launcher.png | The dock on the left, the launcher open over tiles |
| 03-floating-and-snap-preview.png | Floating windows with centred title bars, a snap preview over the right half |
| 04-launcher-glass-A-rejected.png | Launcher glass, option A (rejected) |
| 05-launcher-glass-B-chosen.png | Launcher glass, option B (chosen) |
| 06-light-theme.png | The light theme: windows, launcher, dock |
| 07-spec-sheet-at-2x.png | Spec sheet: title bar states, dock metrics, icons, selection and focus, buttons, type ramp, shadows, radii, glass, tokens |
| 08-behaviour-schematic-at-2x.png | Placement zones (diagonals, 23.6% centre), placement with four columns, gap geometry, snapped groups |
